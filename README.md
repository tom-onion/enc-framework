# CryptoShield

## Overview
CryptoShield is an advanced encryption framework designed to securely encrypt and decrypt text using industry-standard algorithms. Built with Web Crypto API and Vite, it ensures data is processed locally, enhancing user privacy.

## Features
- Text encryption and decryption
- Supports AES-256-GCM algorithm
- Key management
- File encryption
- Hash generation
- Security logs

## Usage
1. Select "Encrypt" or "Decrypt" mode.
2. Choose an algorithm (e.g., AES-256-GCM).
3. Enter a password and plain text.
4. Click "Encrypt Text" to process.

## Installation
1. Ensure Node.js is installed.
2. Clone the repository: `git clone https://github.com/tom-onion/enc-framework.git`
3. Navigate to the project directory: `cd crypto-shield`
4. Install dependencies: `npm install`
5. Start the development server: `npm run dev`
6. Open the provided URL (e.g., `http://localhost:5173`) in your web browser.
